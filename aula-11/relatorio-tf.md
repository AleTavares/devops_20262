## Resumo da Atividade Aplicada

### Objetivo
Avançar no **Moodle Docker AWS Challenge** ([github.com/AleTavares/implement_Moodle](https://github.com/AleTavares/implement_Moodle)), aplicando na prática os conceitos de containerização e infraestrutura como código vistos até aqui, com foco em iniciar a estrutura do projeto e validar o ambiente Docker local do template.

### Tarefa
Fazer um fork do repositório `implement_Moodle`, clonar localmente e executar `docker compose up -d` dentro do diretório `docker/` para validar que o Moodle sobe em `http://localhost:8080` com PostgreSQL 15. Explorar a estrutura do repositório (`CHALLENGE.md`, `docs/`, `tests/`, workflows existentes) para entender os entregáveis da prova. Registrar o progresso com um commit no fork, preencher o relatório descrevendo o que foi feito e as dificuldades encontradas, e entregar via Pull Request no repositório da disciplina em `entregas/aula-11/RA/`.

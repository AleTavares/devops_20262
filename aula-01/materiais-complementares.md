## Prática Extra

Se quiser praticar mais antes da próxima aula:

### Git

1. **Learn Git Branching** — Complete os níveis "Introduction Sequence" e "Ramping Up"
2. **GitHub Skills** — Faça o curso "Introduction to GitHub"
3. **Exercício livre** — Crie um repositório pessoal e pratique o ciclo `add → commit → push` com diferentes arquivos e branches

### Docker

4. **Play with Docker** — Acesse o ambiente online e pratique os comandos sem instalar nada
5. **Desafio de tamanho** — Construa a mesma imagem usando `node:20` (Debian) e `node:20-alpine`. Compare os tamanhos com `docker images`
6. **Explore o Docker Hub** — Rode containers de `nginx`, `postgres` e `redis` para ver como funcionam
7. **Variáveis de ambiente** — Modifique o Dockerfile para usar `ENV` e rode com `-e PORT=4000`

### Integrado (Git + Docker)

8. **Fluxo completo** — Crie um novo repositório, adicione uma app simples, containerize e publique tudo no GitHub. Peça para um colega clonar e rodar.

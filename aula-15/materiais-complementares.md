## 🎓 Certificações Recomendadas

As certificações abaixo priorizam a stack efetivamente praticada no curso (AWS, Terraform, GitHub Actions, Docker) — alinhadas ao que você construiu.

### Nível Iniciante

| Certificação | Organização | Foco | Custo Aprox. |
|--------------|-------------|------|--------------|
| AWS Cloud Practitioner | Amazon | Cloud fundamentals | ~100 USD |
| GitHub Foundations | GitHub | Git e GitHub | Gratuito |
| GitHub Actions | GitHub | CI/CD com Actions | ~99 USD |

### Nível Intermediário

| Certificação | Organização | Foco | Custo Aprox. |
|--------------|-------------|------|--------------|
| AWS Solutions Architect Associate | Amazon | Arquitetura cloud | ~150 USD |
| HashiCorp Terraform Associate | HashiCorp | IaC com Terraform | ~70 USD |
| Docker Certified Associate | Docker/Mirantis | Containers | ~195 USD |

### Nível Avançado

| Certificação | Organização | Foco | Custo Aprox. |
|--------------|-------------|------|--------------|
| AWS DevOps Engineer Professional | Amazon | DevOps na AWS | ~300 USD |
| AWS SysOps Administrator Associate | Amazon | Operação na AWS | ~150 USD |
| Linux Foundation LFCS | Linux Foundation | Linux na prática | ~395 USD |

### Roteiro Sugerido de Certificações

```
Etapa 1:  GitHub Foundations (gratuito) → base sólida
Etapa 2:  AWS Cloud Practitioner → entender cloud
Etapa 3:  Terraform Associate → dominar IaC
Etapa 4:  AWS Solutions Architect Associate → arquitetura cloud
Etapa 5:  AWS DevOps Engineer Professional → consolidar DevOps na AWS
```

## 💼 Carreira em DevOps

### Cargos e Faixas (mercado brasileiro)

| Cargo | Experiência | Faixa Salarial (CLT) | Habilidades-Chave |
|-------|-------------|---------------------|-------------------|
| DevOps Junior | 0-2 anos | R$ 4.000 - 7.000 | Linux, Docker, CI/CD básico |
| DevOps Pleno | 2-4 anos | R$ 8.000 - 14.000 | Terraform, AWS, monitoramento |
| DevOps Sênior | 4-7 anos | R$ 15.000 - 25.000 | Arquitetura, liderança técnica |
| SRE | 3-6 anos | R$ 12.000 - 22.000 | SLOs, incident management, automação |
| Platform Engineer | 4-7 anos | R$ 14.000 - 25.000 | IDPs, DX, abstrações |
| Staff/Principal | 7+ anos | R$ 25.000+ | Estratégia, mentoria, arquitetura org |

*Valores aproximados e variáveis por região e empresa.*

### Habilidades Mais Demandadas

1. **AWS/Azure/GCP** — pelo menos uma cloud em profundidade
2. **Terraform** — infraestrutura como código
3. **CI/CD** — GitHub Actions, GitLab CI, Jenkins
4. **Docker e registries** — containerização e distribuição de imagens
5. **Python/Go** — automação e ferramentas
6. **Linux** — fundamentos sólidos
7. **Observabilidade** — Prometheus, Grafana, CloudWatch, logs
8. **Segurança** — DevSecOps, compliance
9. **IA/Automação** — LLMs aplicados a operações
10. **Comunicação** — documentação, incidentes, colaboração

### Dicas para o Primeiro Emprego em DevOps

1. **Mantenha o portfólio atualizado** — é seu melhor cartão de visitas
2. **Contribua para open source** — mostra iniciativa e habilidade real
3. **Escreva sobre o que aprende** — blog posts, LinkedIn, dev.to
4. **Participe de meetups** — networking é fundamental
5. **Pratique em projetos pessoais** — suba uma infra com Terraform, configure um pipeline
6. **Não espere saber tudo** — ninguém sabe. Mostre que aprende rápido
7. **Certificações ajudam** — especialmente no início da carreira

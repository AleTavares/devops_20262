## Resumo da Atividade Aplicada

### Objetivo
Demonstrar domínio de provisionamento de infraestrutura de rede na AWS com Terraform, criando uma VPC Multi-AZ com subnets públicas e privadas, Security Groups com menor privilégio, e uma instância EC2 com User Data para bootstrap automático da aplicação.

### Tarefa
Criar uma infraestrutura VPC + EC2 Multi-AZ completa para a TechNova usando Terraform, com: VPC customizada, 4 subnets distribuídas em 2 Availability Zones (2 públicas + 2 privadas), Internet Gateway, Route Tables, Security Groups para API e banco de dados, instância EC2 com User Data que instala e inicia a aplicação automaticamente, e Instance Profile com IAM Role para acesso ao S3. Todos os recursos devem ser tagueados e o ambiente deve ser destruído após captura das evidências.
